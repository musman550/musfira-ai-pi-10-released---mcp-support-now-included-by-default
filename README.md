## Overview

This is the Pi 1.0 release announcement

The Pi 1.0 release is a significant milestone in the development of the Raspberry Pi single-board computer project. This release marks the inclusion of MCP (Microcontroller Platform) support by default, providing users with a more versatile and expandable platform. The inclusion of MCP support enables users to easily integrate microcontrollers into their projects, expanding the possibilities for applications such as robotics, automation, and IoT development. This update is a major step forward for the Pi project, allowing users to explore new and innovative ideas.
